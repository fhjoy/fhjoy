## Featured project

### [RoleNaviq — Job Application Management Platform](https://github.com/fhjoy/rolenaviq)

An end-to-end platform for application tracking, dashboards, Kanban workflows and interview planning.

- **Frontend:** React, TypeScript, TanStack Query, React Hook Form, Zod, Tailwind CSS and route-level lazy loading
- **Micro-frontend:** separately deployable Angular interview-preparation application
- **Backend:** Node.js, Express, MongoDB, Mongoose and JWT authentication with HttpOnly cookies
- **Quality:** Vitest, React Testing Library, Supertest and Cypress
- **Delivery:** Docker Compose, GitHub Actions, Vercel, Render and MongoDB Atlas
- **Roadmap:** Python/FastAPI service for AI document analysis, LLM/RAG workflows and matching
